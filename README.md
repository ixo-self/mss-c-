# ✦ 永恆深淵 · 終端中樞 (AbyssCore C# .NET 8) ✦

高效能 Discord API 自動化管理與伺服器架構重組開源專案。

基於現代 C# (.NET 8) 架構打造，整合原生 `SocketsHttpHandler` 連線池化技術、主動式動態令牌桶（Proactive Token Bucket）與兩階段全並發流水線，專為極致吞吐量與低延遲通訊設計。

---

## ✦ 專案核心特色

* **主動式動態令牌桶（Proactive Token Bucket）**：
  * 本地主動解析 `X-RateLimit-Bucket` 狀態，預先在本地微秒級睡眠，告別 429 衝撞與 RTT 浪費。
* **原生連線池調度（SocketsHttpHandler）**：
  * 長效 TCP 連線池化復用（`PooledConnectionLifetime`），徹底根除 Windows 通訊埠耗盡（Socket Exhaustion）。
* **八步全景重構流水線（Eight-Step Pipeline）**：
  * ① **防誤踢私訊**：向身分組在機器人自身之下之成員發送永久邀請碼（`wWB2RcR7pX`），防誤踢失聯。
  * ② **全量架構備份**：全量導出伺服器架構 JSON 存檔至本地。
  * ③ **階梯成員處分**：優先拔除 Webhook ➔ 優先封鎖外部 Bot ➔ 全面處分低階成員。
  * ④ **舊架構清理與重塑**：同步清理舊類別、舊頻道、舊身分組，並套用品牌主題。
  * ⑤ **高並發建置**：同步極速建立 **150 個迷宮頻道** 與 **50 個迷宮身分組**。
  * ⑥ **表情包清理與替換**：清理舊表情與貼圖，極速灌入滿額專屬星輝結晶可愛表情包。
  * ⑦ **伺服器頭像替換**：自動將伺服器圖示替換為深淵星門專屬高畫質主題頭像。
  * ⑧ **頂端頻道日誌發布**：重構完畢後自動於伺服器最頂部第一個頻道輸出全量統計報告。
* **私訊管理員雙向中樞（DM Admin Hub）**：
  * 支援批量向伺服器全體真人管理員發送私訊通知（預設 10 次）。
  * 支援管理員直接於 Discord 私訊（DM）向機器人發送 `.mss>` 管理指令進行遠端遙控。
* **全量架構備份與智慧權限覆寫還原（Advanced Backup & Restore）**：
  * 完整序列化伺服器身分組、類別、頻道、權限覆寫矩陣（Permission Overwrites）與 NSFW 狀態。
  * 智慧映射矩陣（Role Mapping Table）：自動將新舊身分組 ID 完美綁定，徹底杜絕權限覆寫遺失與 400 Bad Request 錯誤。
* **安全防護、前置權限巡檢與本地審計日誌（Safety & Audit Engine）**：
  * 前置檢查機器人自身管理員（Administrator）、踢出、封鎖、禁言、管理頻道與身分組之位元特權。
  * 身分組位階動態防護：嚴禁對機器人自身、伺服器擁有者或位階高於自身之管理員執行違規處分，防止 403 Forbidden 異常。
  * 本地審計日誌：所有敏感操作自動記錄於 `backups/audit.log`。
* **限制級等級與全服頻道 NSFW 開關（NSFW Controller）**：
  * 支援設定伺服器整體 `nsfw_level`（0: 預設, 1: 包含成人內容, 2: 安全, 3: 年齡限制）。
  * 支援多並發一鍵切換全服所有文字頻道為 NSFW 限制級或普遍級。
* **全功能矩陣**：
  * 支援 7 大世界觀主題預設集切換。
  * 支援精確單人/全服禁言、解除禁言與成員踢出。
  * 支援頻道/身分組/成員暱稱三向一鍵批量更名。
  * 支援文字頻道多輪廣播與全體禁言處分。

## ✦ 快速開始指南

### 1. 複製專案與建立設定檔
```bash
git clone https://github.com/your-username/AbyssCore.git
cd AbyssCore
```

將設定範本複製為正式設定檔：
* 複製 `config.example.json` 為 `config.json`，並填入您的 Discord 機器人 Token。
* 複製 `texts.example.json` 為 `texts.json`（可根據需求自訂頻道與身分組名稱清單）。

```json
// config.json
{
  "token": "YOUR_DISCORD_BOT_TOKEN"
}
```

### 2. 編譯與執行
使用 .NET CLI 直接啟動：
```bash
dotnet run
```
或在 Windows 環境下直接雙擊執行：
```cmd
啟動_CSharp終端.bat
```

## ✦ Discord 聊天室與私訊 (DM) 旗艦指令清單

支援在**伺服器任何文字頻道**或**管理員與機器人之 Discord 私訊 (DM)** 中直接輸入觸發：

| 指令語法 | 核心說明 |
| :--- | :--- |
| `.mss>幫助` | 顯示完整文字指令說明清單 |
| `.mss>清理` | 啟動全服 8 步深度重構管線（防誤踢私訊->備份->成員處分->類別頻道重塑->建迷宮->換表情->換頭像->頂部發布日誌） |
| `.mss>私訊 [次數] [內容]` | 批量向伺服器全體真人管理員連續發送私訊通知（預設 10 次，內容預設「迷宮以開啟」） |
| `.mss>踢出 <@用戶/ID> [原因]` | 踢出指定成員（具備階級保護校驗與審計日誌記錄） |
| `.mss>禁言 <@用戶/ID> [分鐘] [原因]` | 單人精確禁言（1-40320 分鐘，支援位階防護） |
| `.mss>禁言 [分鐘]` | 全服批量禁言身分組低於機器人之可處生成員 |
| `.mss>解禁 <@用戶/ID> [原因]` | 立即解除指定成員之禁言處分（Unmute） |
| `.mss>限制級 [開/關/0-3]` | 設定全服限制級等級 (0:預設, 1:成人, 2:安全, 3:年齡限制) 及文字頻道 NSFW 屬性 |
| `.mss>安全` 或 `.mss>巡檢` | 執行前置安全巡檢，評估機器人管理特權與伺服器階級結構 |
| `.mss>頻道 [數量]` | 批量建立迷宮文字頻道（預設 50，最高 500） |
| `.mss>身分組 [數量]` | 批量建立迷宮身分組（預設 20，最高 100） |
| `.mss>表情 [數量]` | 滿額表情包置換（清空舊表情貼圖並灌入可愛表情包） |
| `.mss>頭像` | 一鍵將伺服器頭像替換為深淵星門專屬主題頭像 |
| `.mss>訊息 [輪數] [內容]` | 批量向全服文字頻道廣播迷宮提示 |
| `.mss>更名 [目標名稱]` | 批量統一名稱（頻道/身分組/成員暱稱） |
| `.mss>備份` | 序列化導出身分組、類別、頻道與權限覆寫 JSON 備份檔 |
| `.mss>還原 [編號]` | 從本地備份智慧映射還原身分組與權限覆寫矩陣 |
| `.mss>主題 [1-7]` | 即時切換世界觀外觀主題（1.深淵 2.廢墟 3.救贖 4.月之 5.森林 6.寒冰 7.時空） |

## ✦ 安全與隱私聲明 (Security & Privacy)

* 本開源專案**絕不內建任何 Token 或私密金鑰**。
* `.gitignore` 已嚴格配置排除 `config.json`、`texts.json` 與 `backups/` 目錄，確保上傳至 GitHub 時不會洩漏任何憑據或伺服器架構資料。
* 僅供軟體架構研究、分散式高並發連線控制與合法授權之伺服器維護測試使用。請勿用於任何違反 Discord 服務條款之未授權行為。
